claudeknows where things are

Show it a photo and it finds your water bottle, keys and shoes, draws a box around each one, and says how far away each is.

  • Where is itA labelled box around every bottle, set of keys or shoe, several per photo.
  • How far awayNearest to farthest, plus rough metres. The order is reliable; the metres are estimates.
  • Any angleTrained on tilted, turned, zoomed and shifted photos so position doesn't throw it off.
about 5 minutes

Try it on your photos

Uses a model you already trained. No training.

  1. Open the notebook and choose Runtime → Change runtime type → T4 GPU.
  2. Runtime → Run all. Say yes to Google Drive.
  3. Upload photos when the button appears.
Open “try it” notebook
about 45–60 minutes

Train or retrain it

Downloads the photos, adds your footage, trains, scores itself, and saves the model to your Drive.

  1. Same GPU setting, then Runtime → Run all.
  2. Keep the laptop open until it finishes.
  3. The model is saved to claudeknows_models/ in Drive automatically.
Open training notebook

Train first. The “try it” notebook needs a model from the training notebook. Run training once, and after that “try it” works any time.

What to film (in Google Drive, never on GitHub)

claudeknows_photos/water_bottle/Short videos of each object from many angles, walking toward and away, off-centre, partly hidden. Same for keys/ and shoes/.
claudeknows_photos/together/Videos with 2–3 of the objects in the same shot. Matters most for “where is it”.
claudeknows_photos/distance/Photos at a tape-measured distance, named like keys_1.0m.jpg. Only used to check the distance guesses.
